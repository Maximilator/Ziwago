# NEUROWEAVE

Цифровой спайковый организм: **вычисление = память = обучение** в одном
контуре. Этот репозиторий целиком посвящён проекту NEUROWEAVE.

`neuroweave10` — **v10.0 «Genesis»**: реализация GENESIS_MANIFESTO —
четырёхуровневая виртуальная биология (сенсорика→кора→память→сознание)
с мультикомпартментными нейронами Urbanczik-Senn, трёхфакторным
обучением без backprop, Modern-Hopfield Global Workspace, HOT MetaHead,
Attention Schema и гомеостатическим контролем критичности σ≈1.
`neuroweave9` — **v9.0 «Cortex» (The Great Merge)**: гибрид измеренного
пайплайна обучения Spiker v6.0 и инноваций NEUROWEAVE 8.
`neuroweave8` — ламинарный организм v8, используемый v9 как библиотека
ядра (нейрон/синапс/сон/callosum/credit); зафиксирован в `V8_V9_LOCK`.

## Быстрый старт

```bash
pip install torch pytest          # CPU-режим поддерживается из коробки

# v9 «Cortex» — обучение на TinyStories методом «одной большой партии»
python -m neuroweave9.train_cortex --max-stories 200 --holdout 40 \
    --phase1-epochs 4 --phase2-epochs 10 --max-vocab-size 128

# v8 — демо жизненного цикла и бенчмарк
python -m neuroweave8.main --preset poc --steps 200 --batch 4
python -m neuroweave8.bench --sweep --ticks 40   # свип масштабирования

# v10 «Genesis» — демо организма (бодрствование → сон → отчёт)
python -m neuroweave10.main --preset tiny --steps 120

pytest tests/                     # 80+ тестов: v8 ядро/организм/скейлинг + v9 cortex + v10 genesis
```

- **Химия**: `chemistry/modulators.py` — DA/NE/ACh/5-HT/Orexin/

- **Единый организм** (`neuroweave10/unified/`): синергия v8+v9+v10 — v9 `TemporalPhaseEncoder` кодирует токены в латентностные спайки с салиентностью → v10 `GenesisOrganism` (таламус/кортекс/гиппокамп/БГ/GW) → v9 `LaplaceContextReadout` превращает PFC-активность в логиты словаря; CE-ошибка замыкает петлю через reward→DA→трёхфакторную пластичность. v8 `sparse_drive`/`k_wta` дают событийную экономию на входе (~1% от dense).

### v10.6 «REGENESIS» — True Bio-Organism

Полный отказ от ML-костылей в генеративном контуре:

- **Моторная кора вместо MLP-декодера** (`motor/pool.py`): `vocab` спайковых нейронов с проводимостной мембраной и ALIF-порогом; входы — L5-афференты, гиппокамп CA1 через NMDA+Mg²⁺-гейт, медленные шкалы Лапласа. Выбор токена — WTA-гонка спайков (первый/максимум за суб-такты), не argmax обучаемых логитов.
- **Усталость вместо вето** (Закон 2): Tsodyks-Markram STP на афферентах моторного пула + аксональная усталость победителя — повтор «found» истощает везикулы (x→0.2 за ~25 мс), петля гаснет биофизикой. Никаких Veto/Repetition Penalty в новом контуре.
- **Торможение — шунт** (Закон 3): сома интегрируется exact-step по проводимостям `V_inf=(Σg·E+I)/Σg`, `V←V_inf+(V−V_inf)·exp(−dt·g_tot/C_m)`; GABA к E_Cl≈−75 мВ — мембрана физически не уходит ниже реверсии хлора.
- **Память и модуляторы в физике** (Закон 4): астроцитарный микродомен (τ_Ca≈2.5 с, щелевая диффузия) ставит `stp_gain` синапсов и θ_Ca плато дендрита; Лапласовы медленные шкалы сдвигают Θ L5; гиппокамп→L5 через NMDA-Mg-гейт праймит кору без спайка.
- **Честная энергия** (Закон 5): аденилатный долг >порога замораживает w_fast; аденозин A1 поднимает Θ (`ado_theta_gain`); OU-шум Орнштейна-Уленбека на мембранах в фазе обучения вместо Scheduled Sampling.

### Генерация: инварианты моторного контура

Токен в автономной генерации выбирает **стриатум** (`BasalGangliaGate`), а не
декодер напрямую. Чтобы это было корректно, генератор обязан соблюдать два
инварианта (иначе моторный тормоз работает не по тому действию):

1. **Гейт вызывается ровно один раз за такт и в пространстве логитов
   декодера.** `org.step()` сам вызывает БГ-гейт на `fused`-логитах коры,
   поэтому генератор обязан вызывать `org.step(..., skip_gate=True)` и
   брать токен из своего единственного вызова гейта по логитам декодера.
   Иначе аккумулятор DDM растёт дважды за такт, а `w_NoGo` остужает не тот
   токен, который произносится.
2. **Вето NoGo — исключение действия, а не вычитание константы.** При
   насыщении кортикального состояния margin декодера вырастает до десятков
   логитов, и постоянный штраф `nogo_gain * w_NoGo` перестаёт его
   пересиливать: модель застревает в периодическом аттракторе. Поэтому
   `configure_nogo_veto(K)` исключает действие, произнесённое подряд
   несколько раз, из набора (по умолчанию вето выключено — `inf`).

Стохастический выбор (`configure_sampling(temperature, top_k, top_p, seed)`)
включается явно; при `temperature <= 0` поведение гейта не меняется ни на
бит, поэтому отчёты остаются воспроизводимыми.

### Генерация: масштаб тета-часов гиппокампа

Гиппокампальный тета-осциллятор при 7 Гц и `dt = 1 мс` делает ОДИН тета-цикл
за **143 шага**, а в текстовом потоке 1 шаг = 1 токен. Поэтому реколл
разрешён раз в 143 токена, тогда как рабочий контекст коры живёт ~32 токена:
к моменту реколла контекст уже мёртв, и SWR-дисинингибиция не успевает
разрушить застрявший кортикальный аттрактор (хвост генерации уходил в
периодическую петлю).

Два режима выравнивания — **рантайм, веса модели не затрагиваются**
(`org.configure_theta_clock(mode, cycle_steps)`):

- `fast` — **вариант А**: биологические 7 Гц сохраняются, пересчитывается
  масштаб времени модели так, чтобы тета-цикл занимал `cycle_steps` шагов
  (1 токен = 143/N мс модельного времени);
- `token` — **вариант Б**: фаза теты считается напрямую от счётчика токенов
  (1 токен = 1/N тета-цикла), часы не зависят от числа внутренних тактов коры.

Третий инвариант: **реколл должен быть один**. Ручной путь реколла в
`generation_4000_tokens.py` (с якорями промпта, `extra_apical` и импульсом NE)
— обходное решение, сделанное ДО подключения внутреннего реколла к быстрому
контуру. Он конкурирует с внутренним реколлом за единственный слот тета-цикла
и при ускоренных часах вредит. Режим `--hippo-recall internal` (по умолчанию)
использует только внутренний реколл организма.

Четвёртый инвариант (опционально): **дивергентный реколл**
(`--hippo-explore`). Nearest-match-реколл возвращает самый похожий эпизод, а
при застревании коры это только **усиливает текущую тему**. Режим explore
выбирает эпизод из сглаженного распределения сходств (`--explore-temp`),
т.е. pattern completion предлагает альтернативу. В связке с градуированным
паттерновым тормозом это и ломает хвостовой дрейф.

Пятый инвариант: **паттерновое торможение в стриатуме** (три уровня).

1. `--ngram-veto-size/repeat/ticks` — ЖЁСТКОЕ вето: если один и тот же
   ПАТТЕРН действий (период 1..N) повторился подряд `repeat` раз, он
   получает вето на `ticks` тактов: действие, которое его продолжило бы,
   исключается из набора.
2. `--ctx-brake-size/threshold` — ГРАДУИРОВАННЫЙ тормоз (D2-MSN на уровне
   action chunk): ключ = (контекст из последних N токенов, произнесённый
   токен); каждая эмиссия добавляет +0.8 к тормозу пары, затухание 0.99/тик
   (медленное: LTP-тормоз снимается диссинингибицией, а не затухает за
   десятки тактов). Превышение порога -> токен исключается из набора **в
   этом контексте**.
3. `--logit-temp` — temperature scaling на выходе декодера (логиты / T).

Измерено на 2000 токенах (`cortex_9800_scheduled.pt`): максимальный margin
декодера 29.9 -> **8.41**, уникальных 4-грамм 535 -> **1428**, доля
уникальных 4-грамм в хвостовом окне 46 % -> **74 %**.

### Обучение: scheduled sampling (Этап 6)

`mini_batch_trainer.py --scheduled-sampling --ss-start 0.0 --ss-end 0.5`
подставляет на вход **собственный предыдущий вывод модели** (цель остаётся
эталонной), с аннелированием доли от `ss_start` к `ss_end`. Работает в обеих
фазах: и колонки Фазы 1, и декодер Фазы 2. Зачем: обучение на teacher forcing
никогда не показывает модели её собственный вывод, поэтому в генерации
состояние уходит с off-manifold, margin декодера взрывается (измерено: до
29.9 логитов, p(top1) → 1.0000) и кора попадает в неподвижную точку.

Полный переобучающий прогон (Фаза 1 + Фаза 2) с выровненными тета-часами и
scheduled sampling запускается идемпотентным лаунчером:
```
run_scheduled.cmd
```
Он переживает падения: чекпоинт после каждой эпохи, `--resume`, до 5
попыток. Контроль состояния декодера при генерации:
```
python probe_generation_loop.py --ckpt cortex_9800_scheduled.pt --tokens 1000 \
    --temperature 0.75 --top-k 40 --theta-mode fast --theta-cycle 16
```
Зонд печатает p(top1), margin, вес NoGo, число реколлов и сводку: связный
префикс, уникальные 2/3/4-граммы, максимальный margin.

Запуск:
```
python -m neuroweave9.generate --ckpt cortex_9800_seq128.pt --prompt "once upon a time" --num-tokens 200
python generation_4000_tokens.py --ckpt cortex_9800_seq128.pt --tokens 1000 --temperature 0.75 --top-k 40 --top-p 0.9 \
    --theta-mode fast --theta-cycle 16 --hippo-recall internal
python probe_theta_cycle.py --ckpt cortex_9800_seq128.pt --tokens 600   # сравнение режимов
```

## Ключевые уровни v8

- **Ламинарная колонна** L4→L2/3→L5→L6 + PV/SST: базальный/апикальный
  тракты разведены физически; дендритное плато L5 = AND-гейт
  «вход И контекст».
- **Гиппокамп** DG→CA3→CA1: паттерн-сепарация, аттракторное
  восстановление, приоритизированный реплей во сне.
- **Обучаемый мета-контроллер**: сетпоинты ACh/5-HT от телеметрии;
  NE = фазический аларм неожиданной неопределённости (Yu & Dayan).
- **Global Workspace** с заявками компетентности и winner-broadcast
  fusion (WTA, ур. 9).
- **Активный вывод**: EFE-внимание (компетентность × новизна → arousal-
  гейн L1), precision-взвешенный PredictiveHead.
- **θ-γ рабочая память** (7±2 слота) внутри каждой области + фазовый VSA.
- **Событийный разреженный путь**: при плотности входа <40% драйв L4
  идёт через sparse gather.
- **Сон**: приоритизированный реплей гиппокампа, мягкая консолидация
  w_fast→w_slow, прунинг, EWC rebaseline; медленный контур с
  гистерезисом по sleep pressure.
- **NeuroSystem** (`organism/system.py`): развёртываемая системная
  граница — boot/эпизоды/авто-сон/телеметрия/save-load/quantize.
- **int8-квантизация** синапсов: ~10x памяти, max|Δw|<0.01, инференс
  на снимках.
- **Масштабирование**: small→poc→wide (до ~144k синапсов), сублинейная
  цена такта; `bench.py --sweep`.
