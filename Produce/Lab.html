Dormant-State Problem

Each neuron stores ~15 state variables (v, a, g_ampa, g_nmda, g_gaba, ca_plateau, ecb_2ag, spine_health, metaplastic_state, theta_ip, alpha_ip, r_ip, prev_ne, refr, last_spike) in dense tensors [N, ...]. At the same time, there are 2-5% of biologically active neurons at any given moment. The remaining 95% are "zombies" that store state but do not participate in computations. We pay with memory for 100% of the neurons, but we use only 5% computationally.

Research question: Are there "event-state" architectures in SNNs where a neuron has a hot state (only during activity), a warm state (recently active, stored in L2/L3 cache), and a cold state (has been silent for a long time, stored in compressed form or on disk)? How can the hierarchy be biologically justified - through threshold adaptation, through ATP homeostasis, or through something else?

Time-Scale Collapse

In a single 1-ms time step we update: synapses (tau ~10 ms) - correct; membrane (tau ~15 ms) - correct; threshold adaptation (tau ~100 ms) - redundant, the same thing is recomputed for 100 consecutive steps; BDNF (tau ~1 s) - 1000x redundant; MTL concepts (tens of seconds) - 10,000x redundant; structural plasticity (minutes) - 100,000x redundant. We spend O(N) work on each variable at each timestep even though biology updates them thousands of times less frequently.

Research question: Is there a formalism for multi-rate discrete event simulation in SNN, where each component has its own clock (dt_syn=1ms, dt_adapt=100ms, dt_BDNF=1s, dt_struct=60s), but the synchronization between them preserves causality and does not break FEP? How does biology solve the problem of "a slow variable should not be invisible to a fast one"?

  • https://arxiv.org/abs/2005.11633 Multi-timescale SRNN closes slow variables with exact exponentials over any interval: alpha=exp(-dt/tau_m), rho=exp(-dt/tau_adp), so a slow state can be advanced by a jump instead of a step.

Hippocampal Serialization

All episodic memory goes through one hippocampus with a capacity of 0.14N (Hopfield limit). With 10M neurons that is 1.4M episodes, and each replay cycle costs O(1.4M). We serialize memory, although in the real brain the hippocampus is distributed: dorsal (space), ventral (emotions), CA1/CA3/subiculum/entorhinal - each stores a different aspect of the same episode.

Research question: How to design a distributed episodic buffer without a single bottleneck: (a) shard by modality (visual / linguistic / emotional), (b) shard by time (fresh / medium / archival), (c) use compositional memory (different aspects of a single episode stored in different shards)? How to preserve pattern completion (from part to whole) in this case?

  • https://arxiv.org/abs/2405.14831 HippoRAG keeps content outside the hippocampus and stores only a sparse index, turning replay into an O(K) join instead of an O(N) sweep.

PLV Fragility

SymphonicChord and PLV (phase-locking value) are calculated between the LFPs of all zones. That is a global sync point: each zone must wait until all the others have updated before coherence can be measured. With 10+ zones this is serialization, and in the real brain the conduction delay between zones is 10-50 ms while our synchronous sim provides zero latency, which is physically unrealistic.

Research question: How to measure local coherence without global sync? Is there a biologically plausible mechanism where coherence occurs locally (for example through electrical gap junctions between neighbors) and only emergently gives global synchronization? What if each zone runs on its own clock and couples with delay, as in the Kuramoto model with delays?

  • https://pubmed.ncbi.nlm.nih.gov/26447583/ Communication through coherence: inter-areal delays plus phase shifts gate signals, so delay is a tunable variable rather than noise to be removed.

Sparsity Tax

The mask is sparse (30-40% density) but F.linear works on a dense matrix, so we pay the full O(N^2) cost to use 0.4N^2. Sparse is a mask, not a speedup. Worse, structural plasticity changes the mask during sleep and breaks the memory layout.

Research question: Are there dynamic sparse kernels (not torch.sparse, but custom ones) that preserve the CSR format when the mask changes (incremental update), use block-sparse with fixed 16x16 blocks (GPU-cache-friendly), and provide a real speedup when density is below 50%? What is the actual crossover density between dense and sparse on real GPUs, not in theory?

  • https://developer.nvidia.com/blog/accelerating-matrix-multiplication-with-block-sparse-format-and-nvidia-tensor-cores/ Blocked-ELL SpMM beats dense only below ~40% density on Volta and ~50% on Ampere, and only when whole 16x16 blocks empty out.

Output Bottleneck

The WTA motor pool for 512 words is 512 neurons. For 50,000 words it is 50,000 neurons each with fan-in from L5: O(50k x N_L5) = 25M parameters at the output, and the WTA race needs top-k over 50k, which is O(V log V) per token. In the real brain the motor cortex does hierarchical motor control - syllable to word to phrase - not one WTA per vocabulary item.

Research question: Is there a biologically plausible hierarchical decoder in SNN (like hierarchical softmax) where the motor cortex operates on syllabic units (~100-1000), word-level representation is a composition of syllable patterns, and phrase-level is a composition of word patterns - reducing output complexity from O(V) to O(sqrt(V)) or O(log V)?

  • https://arxiv.org/abs/1609.04309 Adaptive softmax gives O(d sqrt(k)) cost with 2-10x speedups over full softmax - the arithmetic that a syllable-then-word SNN race would reproduce.

Forgetting Scaffold

Interleaved Replay and the Metaplastic Shield protect weights, but that is post-facto protection: the network does not know in advance which synapses are critical. In the real brain there is scaffolding - basic connections such as "cat-sat" form first and are physically protected from reorganization by myelin and perineuronal nets, while "cat-dragon-mountain" connections stay dynamic and rewrite easily.

Research question: How to design structural scaffolding in SNN: (a) the first N% of synapses have a hard mask that never changes; (b) the next group has soft masks that change only over long time windows; (c) the last are fully plastic. How does biology distribute these three types (perineuronal nets, myelin, dendritic spines)?

  • https://arxiv.org/abs/1703.04200 Synaptic Intelligence accumulates a per-synapse path integral - a cheap continuous importance score to decide which edges get the hard mask.

Unembodied FEP

The brain is not embodied: the free-energy principle is applied to next-token prediction, not to survival. The model has no state of its own world beyond the text and no action other than choosing the next token, so prediction error is never closed by an act.

Research question: How to implement a minimal embodied loop where the model has (1) the state of the world - not only text but the hidden state of the environment - and (2) actions that are not only token selection but also requesting a trace, moving attention, or probing, so that expected free energy can be reduced by acting as well as by predicting?

  • https://arxiv.org/abs/2001.07203 Discrete-state active inference splits expected free energy into epistemic and pragmatic terms, which is the arithmetic a probe/attend/stop action head needs.
