Задача: Масштабирование Ziwago-Prime до словаря GPT-2 (50 257 токенов) . 

Мы доказываем, что спайковая сеть может выучить 50 000 токенов, используя биологическое VSA-связывание морфем. Архитектура коры остается прежней (v9.0), меняется только Входной Энкодер (Input Interface).

ВАЖНО: Все необходимые данные уже загружены в директорию `data/`. Не трать время на их скачивание. Доступны:
- `data/wikitext-103-raw-v1/` (текстовые файлы .raw)
- `data/gpt2/vocab.json` 
- `data/gpt2/merges.txt`

Твои задачи:

1. Архитектурное изменение (Входной Энкодер):
   - Откажись от плотной матрицы эмбеддингов `[50257, 2048]`.
   - Внедри Композиционный VSA-Энкодер (Compositional VSA Encoder):
     * Храни базовый словарь из 2048 самых частых BPE-токенов (байты, артикли, частые корни). Создай для них статические SDR-паттерны.
     * Для остальных 48 000 токенов НЕ храни статических векторов. Используй BPE-дерево (из `data/gpt2/merges.txt`), чтобы разбить токен на базовые компоненты, и ВЫЧИСЛЯЙ его SDR-паттерн на лету через VSA-связывание (Sparse Block Codes или циклический сдвиг).
   - Подавай результат на вход `HashedCorticalSDREncoder` (2048 нейронов, 40 активных).

2. Подготовка данных (Bio-Corpus):
   - Напиши оптимизированный парсер для `data/wikitext-103-raw-v1/`. 
   - Используй 32 ядра CPU для параллельной токенизации текста через `vocab.json` от GPT-2. 
   - Сформируй тензоры последовательностей ID (0..50256) для обучения (достаточно взять 10-50 млн токенов для первого этапа).

3. Биологическое Обучение (FEP + STDP + Sleep):
   - Обучение идет только через локальные правила (STDP, Synaptic Intelligence, CT-PNN).
   - Никакого Cross-Entropy и Backpropagation. 
   - Сохрани механизмы Surprise-Driven Replay (запись в SBC-VSA-DHT только сложных эпизодов) и Progressive Context Window.
   - Anti-Attractor (Down-phase Hysteresis) должен работать для предотвращения зацикливаний.

4. Метрики и Валидация:
   - Surprise (F(t)): стабильное падение на протяжении 10-20 эпох.
   - OOV-тест: подай слово, которого нет в словаре ("cryptodragon"). Модель должна собрать его из морфем ("crypto" + "dragon") и корректно вписать в контекст.
   - Context Retention: способность удерживать контекст на 1000+ токенов.

5. Среда и Артефакты:
   - Напиши `train_ziwago_v9_gpt2vocab.py`.
   - Запусти Pilot Run на CPU (1 млн токенов WikiText-103). Покажи график Surprise, пример OOV-генерации и подготовь ZIP-архив для запуска на GPU.

Действуй. Цель — доказать, что 26 МБ спайкового VSA-мозга могут говорить на языке GPT-2, используя чистую биологию.
